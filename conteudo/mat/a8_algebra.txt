fonte: AE Matemática 8.º ano, Expressões algébricas (polinómios)
#A
- Somar, subtrair e multiplicar polinómios.
- Usar os casos notáveis.
- Escrever um polinómio na forma reduzida e dizer o grau.
#C
- Multiplicar: cada termo de um por cada termo do outro.
- Quadrado do binómio: (a + b)² = a² + 2ab + b²; (a - b)² = a² - 2ab + b².
- Diferença de quadrados: (a + b)(a - b) = a² - b².
- Cuidado: (a + b)² não é a² + b².
- Forma reduzida: juntar os termos semelhantes e ordenar pelo grau.
#E
@F Quadrado do binómio|(a ± b)² = a² ± 2ab + b²|a, b: monómios|o termo do meio é o dobro do produto|(x + 3)² = x² + 6x + 9|c_mpol.pol
@F Diferença de quadrados|(a + b)(a - b) = a² - b²|a, b: monómios|soma vezes diferença|(x - 1)(x + 1) = x² - 1|c_mpol.pol
#F
Dados: (x + 3)² - (x - 1)(x + 1).
Objetivo: forma reduzida e valor para x = 2.
1. (x + 3)² = x² + 6x + 9.
2. (x - 1)(x + 1) = x² - 1.
3. x² + 6x + 9 - x² + 1 = 6x + 10.
4. Para x = 2: 6 × 2 + 10 = [[22]]
> 6x + 10 (grau 1); vale 22 para x = 2.
Verificação: (2 + 3)² - 1 × 3 = [[22]] ✓.
#J
Desenvolve (2x - 5)².
#R
4x² - 20x + 25 (para x = 1 vale [[9]]).
#V
V = [6 * 2 + 10, (2 + 3) ** 2 - 1 * 3, 4 - 20 + 25]

#A
- Fatorizar pondo um fator comum em evidência.
- Fatorizar com os casos notáveis.
- Resolver equações com a lei do anulamento do produto.
#C
- Fator comum: 2x² - 8x = 2x(x - 4).
- Diferença de quadrados: x² - 9 = (x - 3)(x + 3).
- Quadrado do binómio: x² + 6x + 9 = (x + 3)².
- Lei do anulamento do produto: a × b = 0 ⇔ a = 0 ou b = 0.
- Para resolver: tudo no 1.º membro, fatoriza e iguala cada fator a 0.
#E
@F Lei do anulamento do produto|a × b = 0 ⇔ a = 0 ∨ b = 0|a, b: números ou expressões|um produto é 0 se um dos fatores for 0|x(x - 4) = 0 ⇔ x = 0 ∨ x = 4|c_mpol.fat
#F
Dados: 2x² = 8x e x² - 25 = 0.
Objetivo: resolver as duas equações.
1. 2x² - 8x = 0 ⇔ 2x(x - 4) = 0 ⇔ x = 0 ∨ x = [[4]]
2. x² - 25 = 0 ⇔ (x - 5)(x + 5) = 0 ⇔ x = [[5]] ∨ x = [[-5]]
> C.S. = {0; 4} e C.S. = {-5; 5}.
Verificação: 2 × 4² = [[32]] e 8 × 4 = [[32]] ✓.
#J
Fatoriza x² - 10x + 25.
#R
(x - 5)², um quadrado do binómio (para x = 0 vale [[25]]).
#V
V = [8 / 2, 5, -5, 2 * 4 ** 2, 8 * 4, 25]

#A
- Resolver sistemas pelo método de substituição.
- Classificar um sistema.
- Interpretar a solução como o ponto de interseção de duas retas.
#C
- Isola uma incógnita numa das equações.
- Substitui na outra e resolve a equação com uma só incógnita.
- Volta à expressão isolada para calcular a outra incógnita.
- Possível e determinado: uma solução (retas concorrentes).
- Impossível: retas paralelas; indeterminado: retas coincidentes.
#E
@F Método de substituição|isolar uma incógnita e substituir na outra equação|x, y: incógnitas|sistemas de duas equações do 1.º grau|x + y = 10 e 2x - y = 2: (4, 6)|c_mexp.sis
#F
Dados: x + y = 10 e 2x - y = 2.
Objetivo: resolver o sistema.
1. Da 1.ª: x = 10 - y.
2. Na 2.ª: 2(10 - y) - y = 2, logo -3y = [[-18]].
3. y = -18 : (-3) = [[6]]
4. x = 10 - 6 = [[4]]
> (x, y) = (4, 6): sistema possível e determinado.
Verificação: 2 × 4 - 6 = [[2]] ✓.
#J
Num estacionamento há carros e motas: 20 veículos e 70 rodas. Quantos carros há?
#R
c + m = 20 e 4c + 2m = 70: c = [[15]] carros e 5 motas.
#V
V = [2 - 20, -18 / -3, 10 - 6, 2 * 4 - 6, (70 - 2 * 20) / 2]

fonte: AE Matemática 8.º ano, Funções (função afim)
#A
- Reconhecer uma função afim e o seu gráfico (uma reta).
- Interpretar o declive e a ordenada na origem.
- Escrever a expressão a partir de dois pontos.
#C
- Função afim: f(x) = mx + b; o gráfico é uma reta.
- m (declive): quanto sobe y quando x aumenta 1.
- b (ordenada na origem): onde a reta corta o eixo Oy.
- Com b = 0: função linear (proporcionalidade direta).
- Dois pontos: m = (y₂ - y₁) / (x₂ - x₁); depois b = y₁ - m x₁.
#E
@F Declive|m = (y₂ - y₁) / (x₂ - x₁)|(x₁, y₁) e (x₂, y₂): pontos da reta|x₁ ≠ x₂|(1, 3) e (3, 7): m = 2|c_matf.afim
@F Função afim|f(x) = m x + b|m: declive;b: ordenada na origem|o gráfico é uma reta|m = 2, b = 1: f(x) = 2x + 1|c_matf.afim
#F
Dados: a reta passa em A(1, 3) e B(3, 7).
Objetivo: expressão da função afim e zero.
1. m = (7 - 3) / (3 - 1) = [[2]]
2. b = 3 - 2 × 1 = [[1]], logo f(x) = 2x + 1.
3. Zero: 2x + 1 = 0 ⇔ x = [[-0,5]].
> f(x) = 2x + 1; o zero é -0,5.
Verificação: f(3) = 2 × 3 + 1 = [[7]] ✓.
#J
Um táxi cobra 3,50 € fixos e 0,80 € por km. Quanto custa uma viagem de 10 km?
#R
f(x) = 0,8x + 3,5; f(10) = [[11,50]] €.
#V
V = [(7 - 3) / (3 - 1), 3 - 2 * 1, -1 / 2, 2 * 3 + 1, 0.8 * 10 + 3.5]

titulo: Área de um quadrado aumentado
licao: a8a
calc: c_mpol.pol
#T
Enunciado: o lado de um quadrado mede x cm. Aumenta-se o lado 3 cm. Quanto aumenta a área?
Resolução:
1. Nova área: (x + 3)² = x² + 6x + 9.
2. Aumento: x² + 6x + 9 - x² = 6x + 9.
3. Para x = 5: 6 × 5 + 9 = [[39]] cm².
Resultado: a área aumenta 6x + 9 cm² (39 cm² se x = 5).
Interpretação: 8² - 5² = [[39]] ✓.
Erros a evitar: escrever (x + 3)² = x² + 9.
#V
V = [6 * 5 + 9, 8 ** 2 - 5 ** 2]
